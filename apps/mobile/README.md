# Mobile (frontend)

App Alterno pour Android et le web, en React Native + Expo (React Native Web pour le site).

Organisation par feature (`features/simulation`, `features/deviations`, `features/calendar`…), chacune découpée en `screens/`, `components/`, `hooks/`, `adapters/`. Les composants n'appellent jamais directement la base locale ou l'API.

Initialisation prévue au jalon 2.
